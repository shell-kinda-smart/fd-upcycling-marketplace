# Five-minute Demo Script

1. On the landing page, state the waste/discovery problem and marketplace objective.
2. Open Marketplace and demonstrate text search, category filter and price sorting.
3. Register and sign in; explain password hashing and server sessions.
4. Open Sell, publish an item, then show it in Your Listings and change its status.
5. Add another seller's item to the cart and explain user-specific database ownership.
6. Place a **demo** UPI order and show persistent Order History. Clearly say no real money is charged.
7. Submit a trade proposal on a trade-enabled item.
8. Edit the user profile and show the live Impact page.
9. In the IDE, show `prisma/schema.prisma`, `src/app/actions.ts` and `.env.example` while explaining the stack.
10. Finish with `90_PERCENT_STATUS.md`.

Before class: confirm `DATABASE_URL` points to the `fd_marketplace` PostgreSQL schema, then run `npm run db:setup` once. The demo buyer is seeded automatically. Use no real payment details.
