# Project Plan

The final classroom target is a feature-complete niche marketplace with buyer, seller and administrator roles, identity, catalogue, seller tools, cart, checkout, order history, trade proposals and sustainability metrics. It is documented in `100_PERCENT_COMPLETION.md`.

Future commercial deployment can add a merchant payment account and webhooks, cloud image storage, shipping, monitoring and external notifications. The present build uses a safe payment simulation because live payment credentials are an external business dependency.
